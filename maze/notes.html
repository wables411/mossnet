dev notes

Lost in the Moss · beta demo · last changed 4 november 2026

what this page is

The working list for the maze: what is being improved, what has been suggested, and ideas that are not decided. It changes as the game does. Anyone can read it; only the game itself needs the word.

what the game is

A walk through moss. Eight real places, each one built as a maze, each with the mosses that really grow there. Find the opening in the outer wall and the next place begins, bigger than the last. It is a beta: unfinished, still changing, and things will look wrong, run slow or break.

improvements under way

  • speed: the walls and the moss now draw fewer layers so the walk runs smoother; the scanned rocks and the floor are next
  • phones: not yet measured on real devices, so expect it to run warm or slow on some
  • moss up close: it still reads as a photograph laid over a shape, and wants real depth
  • hanging moss: seen from the side the strips are thin and can look like sticks
  • the canopy overhead is painted blotches, not yet trees

suggestions, not yet done

  • an opening film before the start screen
  • a gamepad, and tilt-to-look on phones
  • recorded night calls and footsteps in place of the synthesised ones
  • records, journal and satchel that follow you from one browser to another
  • a smaller download before the first place opens
  • trees, logs and stones made for the game, in place of the public scans

ideas, not decided

  • more places
  • the same place in another season
  • a Radbro or a Radcat to follow through a maze
  • a page left in the journal for the next walker to find

what is in now

  • eight places: Yakushima, Aokigahara, the Hoh Rainforest, the Williamson Tunnels, Wistman's Wood, Fanal Forest, Puzzlewood, Congaree
  • weather and the hour, rolled again on every visit
  • six native mosses in each place, named at the bottom of the frame; tap a cushion for its spores and its name
  • one small hidden find in each place
  • a book and quill to write in, a satchel, and a torch for after dark
  • each place's animal, which will not let you get close

good to know

  • your records, journal and satchel are kept in this browser only, and may be reset between versions
  • the first place takes a while to load
